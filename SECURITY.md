# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities by opening an issue with the label "security" or by emailing security@example.com (if applicable). We will respond promptly and work with you to address the issue.

## Supported Versions

We provide security updates for the latest stable release branch.

## Best Practices

- Keep your dependencies up to date.
- Use the `.env.example` as a template and never commit your actual `.env` file.
- Review the code that handles audio and screen capture for privacy implications.

Thank you for helping keep Akemi secure!
